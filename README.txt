INSTIVIO OGLĘDZINY v0.2 PWA

To jest wersja przygotowana do publikacji jako PWA.

Pliki:
- index.html
- manifest.webmanifest
- sw.js
- assets/

Aby działała instalacja na iPhonie i tryb offline, aplikacja musi być udostępniona
z normalnego adresu HTTPS (np. GitHub Pages / własny hosting).

iPhone:
1. Otwórz adres aplikacji w Safari.
2. Udostępnij.
3. Dodaj do ekranu początkowego.

Dane oględzin w tej wersji są przechowywane lokalnie na urządzeniu.
Integracja z Kalkulatorem INSTIVIO będzie dodana na końcu.
